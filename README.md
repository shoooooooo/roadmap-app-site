# みちしるべ

端末のブラウザだけに保存する、人生ロードマップの管理アプリです。「今日」「今週」「ロードマップ」の3画面で、小さな行動と目標をつなぎます。最初に表示される項目は架空のサンプルです。

## 開き方

ビルドやログインは不要です。GitHub Pages など、静的ファイルを配るサーバーでこのフォルダーの `index.html` を開いてください。アドレスは末尾に `/` が付く形（例: `https://example.github.io/roadmap-app/`）を使います。パソコン上のファイルを直接ダブルクリックして開く方法（`file://`）では動きません。

## データの扱い

記録は、開いているブラウザの localStorage（キー名 `roadmap-app.v1`）にだけ保存します。外部への送信やアカウントはありません。ブラウザのデータを消すと記録も消えます。画面下部の「データの書き出し・復元」からバックアップできます。

日本時間・月曜始まりです。画面の時間軸に出る生年月は、実在の人物のものではない固定のサンプルです。
